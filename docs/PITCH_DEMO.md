# KOSMOS · live demo на 3–5 минут

Открыть http://127.0.0.1:8011/ и нажать «Начать защиту · Pitch Mode».
Это presentation mode существующего продукта: данные, выбранные сервисы,
приоритеты, сравнение и research state общие. Next/Back переключают видимые
компоненты; Reset Pitch возвращает к задаче, Escape/«Выйти из Pitch» — в продукт.
Reset DSS отдельно снимает locks и временный budget cap. Ничего не применяется
в конструктор без явного действия.

Перед выступлением: открыть приложение, дождаться рекомендации и паспорта.
Для исходного кейса использовать объявленные веса (Reset в «Приоритетах»),
пустой либо сохранённый рекомендованный состав конструктора и Reset DSS.
Пустой конструктор допустим: Lab явно исследует рекомендацию, не заполняя его.
Интернет не нужен; локальный Python-сервер должен работать.

## Рассказ

1. **Задача, 15 секунд.** Четыре сервиса, ограниченный бюджет, проверяемые условия
   запуска. Синтетические данные кейса, без обещаний фактического эффекта.
2. **Пространство, 20 секунд.** 5670 сочетаний → 1031 BASE-допустимый → шортлист
   при текущих приоритетах → рекомендация. STRESS-допустимых 143. «Показать путь
   решения» визуализирует уже рассчитанный отбор, а не имитирует вычисление.
3. **Recommendation, 20 секунд.** AGRI C / ENV A / FLOOD A / TRANS C. C0 1150,8,
   OPEX 311, VPUB 1239, CASH 410,5; KCASH = 410,5 / 311.
4. **Почему этот, 25 секунд.** Относительно второго места с TRANS B: экономия C0
   5 и OPEX 3,5; выше KCASH, но VPUB ниже на 44. Выбор обусловлен текущими весами.
   Второе сравнение — с ближайшей стратегией замены FLOOD на FIRE.
5. **Альтернативы, 25 секунд.** В матрице сравнить максимальный VPUB и минимальный
   C0; прокрутить до запасов/статусов STRESS. Смотрите одновременно показатели,
   дельты, денежные потоки, индексы и ограничения. Полный Explorer находится в Lab.
6. **Official STRESS, 20 секунд.** Нажать STRESS: cap 1300 → 1180,
   запас 149,2 → 29,2. Стоимость и состав сохраняются. Это устойчивость только
   к заданному бюджетному ограничению.
7. **Research / Recovery, 50–70 секунд.** «Исследовать ниже breakpoint» задаёт
   временный cap на 1 млн ниже рассчитанного C0 (для исходного состава 1149,8).
   Исходный портфель FAIL. A показывает минимальную замену сервисов, затем режимов:
   здесь сохраняются сервисы, меняются ENV A→C и TRANS C→A.
   Переключиться на B: фактический diff содержит FLOOD A→FIRE A и изменения режимов.
   Нажать «Зафиксировать FLOOD»: прежний B исчезает, выводятся другие решения.
   Чтобы показать no-solution, задать cap ниже минимума либо нажать «Нет решения»
   на карте переходов. Приложение честно указывает, поможет ли повышение cap.
   Нажать Reset DSS перед возвращением к официальному итоговому решению.
8. **Финансирование, 25 секунд.** Capital C0 отдельно, годовой OPEX и CASH
   отдельно, VPUB отдельно. Выбрать ENV: service gap 2,5 при portfolio gap 0.
   Пройти цепочку заказчик → оператор/поставщик → сервис → пользователь → эффект.
   Роли — предложения команды; подтверждённого контракта нет.
9. **Условия, 20 секунд.** До пилота нужны финансирование, права на данные,
   локальная проверка качества, SLA, ответственность и baseline KPI.
10. **Решение, 20 секунд.** «Сформировать управленческий brief», при необходимости
    скачать Markdown. Рекомендация, объяснение, альтернативы, компромисс, STRESS,
    финансирование и условия собраны из текущего расчёта. Research breakpoint
    включается только в RESEARCH: 9 разделов official / 10 research.

Числа выше описывают сохранённую исходную конфигурацию для подготовки выступления,
а не отдельный источник данных UI. При других весах, locks или составе говорите
числа из приложения. Финансирование и brief следуют активной рекомендации Lab
после запуска исследования; Reset DSS возвращает контекст основного поиска.

## Проверенный локальный запуск

Из основной папки проекта с установленным окружением:

```powershell
./.venv/Scripts/python.exe -B -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8011
```

В рабочем Git-клоне можно использовать существующий Python из основной папки;
запускать команду с cwd клона. Не заменяйте другой сервер на порту 8000.
Исходный путь без внешней сети сохранён: React/Vite build + локальный Python,
без CDN, внешних шрифтов, AI или нового API-провайдера.

Тесты Windows запускать с `$env:PYTHONUTF8='1'`: старый M3 harness использует
`read_text()` без явной кодировки. Без UTF-8 он искажает кириллические ключи JSON
source_hashes и получает ожидаемый отказ strict API в несовместимых источниках.

Ограничения: comparison хранит до трёх составов; заполненное сравнение просит
удалить один и сохраняет все текущие данные. Старые PDF/ZIP-выпуски сохранены,
новый brief скачивается отдельно. Docker-образ этой сессией не пересобирался.
