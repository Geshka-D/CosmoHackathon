# Материалы защиты M5

Генератор заново считает `config/m3_decision.json` + `management.json` + `assumptions.json` на неизменных `case_source/`. Результат содержит записку **12 страниц основного текста**, самостоятельный стресс **1 страницу** и презентацию **12 слайдов**, JSON, финансовый CSV и sensitivity CSV, редактируемые страницы JSON/Markdown и полные протоколы. Источники документов находятся в `backend/app/submission_content.py`; portable layout — `submission_pdf.py`. Дополнительные DOCX/PPTX не нужны для согласованного PDF-комплекта.

После установки закреплённых `requirements.txt` сборка не требует сети, API, ключей или системных шрифтов:

```text
python -X utf8 -B scripts/build_submission.py
python -X utf8 -B scripts/build_submission.py --current
python -X utf8 -B scripts/build_submission.py --output-dir out/m5
```

На Windows с существующим окружением замените `python` на `.venv/Scripts/python.exe`. Команды работают и из другой текущей директории при абсолютном пути к скрипту. Последняя команда создаёт только `out/m5/results/...`; активный LIVE не перезаписывает. Независимому Tester подходит короткий `--output-dir reports/evidence/m5_tester/a`.

`results/m5_current.json` — единственный активный указатель. Команда `--current` проверяет весь manifest и печатает реальные окончательные пути. Короткий layout: `results/m5/<16 hex>/note.pdf`, `stress.pdf`, `slides.pdf`, `bundle.json`, `finance.csv`, `sensitivity.csv`, `content.json`, `content.md`, `protocols.md`, `inputs/`, `source/` и сопровождающие файлы. Не следует выбирать произвольно глубокий Windows-путь: историческая ошибка на 261 символе остаётся ограничением платформы. Long-path settings/ACL/спецпрефиксы генератор не меняет.

Обычный `mkdir` наследует доступ назначения. Сначала строятся и проверяются все байты; затем создаётся staging, выполняется read-back, rename в окончательную папку и полная проверка final paths. Только `os.replace` одного указателя активирует выпуск. При обычной ошибке предыдущий комплект сохраняется; первая неудачная сборка не создаёт current. Успешная неактивная generation после ошибки pointer может остаться для диагностики. Старые generations/negative fixtures не копируются; автоматического retention cleanup нет. Power-loss durability и враждебные concurrent writers не заявляются.

Аналитический release M4, input/result fingerprints, source hashes, веса/population, management/assumptions hashes сохранены в bundle. M5 submission identity включает версии/хеши renderer, Python-исходников, зависимостей и portable font/license. Внешний publication identity — SHA-256 полного manifest `files` с размерами и хешами всех материалов. В каждом PDF видны submission ID, result fingerprint и source-set SHA-256, а полный `identity.json` вложен в PDF. Изменение вёрстки различимо при прежних цифрах. PDF invariant-rendering исключает текущее время и случайные идентификаторы; случайно только имя каталога активации.

В UI «Реализация» JSON, CSV и PDF загружаются вместе с показанным аналитическим результатом; нажатие кнопки сохраняет уже полученные байты без второго HTTP-запроса. Новая публикация не подменяет скачивание старого отображённого выпуска. При несовпадении аналитической конфигурации PDF скрыты до пересборки; при повреждении текущего выпуска раздел возвращает ошибку. Ручной другой состав имеет собственный расчёт и не получает договорный текст сохранённого решения.

Основная записка содержит П1–П9; `protocols.md` сохраняет полные поля условий/участников, десять KPI-протоколов, риски и ресурсы R1–R5 без потери подробностей. Это редактируемое приложение, без включения в число 12 страниц. `inputs/` и `source/` позволяют просмотреть происхождение и внести изменение в полном репозитории. Самостоятельная папка выпуска не заменяет полный репозиторий с разрешённым `case_source/`; чистый программный комплект и контейнер проверяются M7.

DejaVu Sans включён с лицензией в `assets/fonts/`; никаких CDN/личных bundled путей в production-коде нет. Внешние факты сохранены в принятых M4 sources с датами чтения и ограничениями; M5 их не обновляет. Синтетические числа не рыночные цены. Договоры/местный SLA/численные KPI не подтверждены; публикация в GitVerse или интернет не выполнялась.


## Уточнение ORG

Существующие карточки AGRI C / ENV A / FLOOD A / TRANS C уточняют продукт→действие→пользу, условную классификацию доступа, выбор зрелого измеримого сервиса либо пилота неизвестного местного применения, вклады/обратную связь и ограниченный порядок при внезапной потере доступа. Полные условия и 10 плановых KPI — в management/protocols, краткие выводы — в основных 12 страницах и 12 слайдах; стресс остаётся отдельной страницей. Реальные спрос, договоры, SLA, ресурсы и достигнутые KPI не заявляются.

M4 render-контракт /4 различает новое содержание и сохраняет точный рендер прежних /2 и /3 поколений. Сборщики создают новые identity без изменения исходного решения, чисел, весов, рангов и source/result fingerprints. O1–O5: предоставленные PDF с точными физическими страницами, DOI и SHA-256 в sources. Полные статьи частные, не обязательная зависимость runtime или публичной поставки. Внешние ссылки и библиография заново не проверялись.
