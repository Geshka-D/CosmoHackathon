# Стресс-резюме: текущий выпуск

Полный текст и численные таблицы находятся в проверяемом пятифайловом выпуске M4. Этот файл — навигация; он не содержит отдельной копии расчёта.

Из корня проекта выполните:

```powershell
.venv/Scripts/python.exe -X utf8 -B scripts/build_management.py --current
```

Команда проверяет единый текущий выпуск и показывает все пять путей; откройте `docs/stress-summary-draft.md` в указанной папке. [Механизм выпуска и воспроизведение](implementation.md), [текущий manifest](../results/m4_current.json).

Исходный M4 до исправления сохранён в неизменяемом snapshot M4_FIX1; он не является текущим выпуском.
