# Независимые проверки

Tester прямо разрешено создавать здесь независимые human-authored tests, fixtures и доказательства после прекращения записей Coder. Нельзя исправлять production или ослаблять исходные критерии. Приоритетны собственные ожидаемые значения, 24 пары, агрегирование, 9 условий/границы, дефект 5 строк с 4 ID, BASE/STRESS и позднее весь перебор/интерфейс/документы.

Оригинальный verify_case.py не найден; новый verifier Tester должен иметь явное происхождение. `scripts/m0_audit.py` — ограниченная проверка Coder, не независимый результат Tester. Координация и приёмка только через Main/Evaluator.
