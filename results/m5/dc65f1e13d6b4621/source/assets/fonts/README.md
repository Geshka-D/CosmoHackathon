# Переносимый шрифт

DejaVu Sans (неизменённый TTF) включён для кириллицы и одинаковой вёрстки без системных шрифтов или CDN. Лицензия Bitstream Vera / Arev: `LICENSE-DejaVu.txt`; изменения DejaVu находятся в public domain. Шрифт разрешено встраивать и распространять вместе с этой лицензией.

Источник TTF: локальная поставка Poppler runtime, DejaVu Sans. Лицензия получена из upstream `dejavu-fonts/dejavu-fonts`, tag `version_2_37`, файл `LICENSE`. Генератор не загружает шрифт из сети. Точный SHA-256 TTF и лицензии входит в identity каждого M5-выпуска.
