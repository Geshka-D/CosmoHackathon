# Frontend

React/TypeScript/Vite, без UI-библиотек и без сетевых зависимостей. Python отдаёт production-сборку `frontend/dist`. Запуск — `README_RUN.md`, конфигурационный JSON — `docs/api.md`.

## Файлы

`App.tsx` — рабочее пространство: каталог, ручной состав, localStorage, import/export, история отмены. `useDecision.ts` — состояние решения (метод, веса, сценарий, шортлист, baseline) поверх `/api/decision-method` и `/api/decision/recompute`; debounce, abort и правило ревизий те же, что были в `DecisionPanel`. `decision.ts` — типы контракта и чистые помощники (`portfolioId`, `composition`, `changes`, `differenceCount`, `plural`).

`DecisionAtlas.tsx` — первый экран: сценарий, профиль, рекомендованный состав, вклад в score, вердикт STRESS и воронка с фактическими counts. `DecisionPanel.tsx` — раздел «Поиск и выбор»: приоритеты, доказательство выбора, шортлист, стратегии, рекомендация, чувствительность. `PreferencePanel.tsx` — веса и нормирование вектора. `TradeoffPlot.tsx` — проекция C0×VPUB. `ComparisonMatrix.tsx` — плотная матрица сравнения. `ServiceMap.tsx` — условная аксонометрическая схема «сервисы → кто платит → территории». `StressPanel.tsx` — BASE/STRESS как два условия одного состава, предпросмотр и возврат. `ResultPanel.tsx`, `Comparison.tsx`, `ImplementationPanel.tsx`, `api.ts`, `presentation.ts`, `types.ts` — без изменений с M2–M4.

Экономических формул на клиенте нет: все метрики, ранги, дельты стратегий, запасы и диагностики приходят с сервера. Клиент считает только представление — доли на шкале, позиции точек и точное сравнение наборов лотов.

## Дизайн

«Инженерный атлас решения»: тёплая рабочая поверхность `#ece8e1`, графитовая структурная рамка `#1b2126`, тонкие линии и координаты, один холодный акцент `#0f5468` для выбранного решения и сдержанный янтарный `#8a5510` для условия STRESS. Статусы: `#2a5c46` / `#8f3227`. Шрифты только системные: Bahnschrift — заголовки и крупные величины, Segoe UI — текст и формы, Consolas — коды и идентификаторы; все числа — tabular numerals. Внешних шрифтов, CDN и фоновых запросов нет.

Движение короткое и связано с задачей: доли воронки и весов, перенос бюджетной границы BASE/STRESS, подсветка выбранного варианта. `prefers-reduced-motion` отключает переходы, видимый фокус и клавиатурная навигация сохраняются, значения остаются доступны без анимации. Пространственная схема — обычный SVG без WebGL; её данные продублированы текстом рядом.

## Проверка

`npm run typecheck`, `npm run build`, `npm run test:browser` (Playwright, `KOSMOS_BASE_URL` — адрес работающей сборки). Регрессии репозитория: `node tests/m6_browser.mjs <url> - <out>` и `node tests/m3_browser.mjs <url> <oracle-dir> <out>`.
