# Frontend — M2

React/TypeScript/Vite: App — редактирование, ревизии, import/restore и localStorage; ResultPanel — канонические метрики/девять diagnostic/provenance; Comparison — независимые снимки вариантов; api — настоящий HTTP; presentation — подписи и форматирование, без экономических формул. Python отдаёт production-сборку frontend/dist. Запуск — README_RUN.md, конфигурационный JSON — docs/api.md.

Дизайн: спокойная аналитическая рабочая область. Палитра: navy #193c57, ink #233b4c, blue #245f8a, paper #edf2f5, green #216754, red #9a362e. Bahnschrift — заголовки/крупные величины, Segoe UI — формы/таблицы, Consolas — коды/происхождение; только локальные системные шрифты. Четыре позиции кодируют реальное число лотов. Выразительный элемент — строка «стоимость / лимит / запас», которая объясняет бюджетный компромисс. Нет декоративной анимации или внешних ресурсов.
