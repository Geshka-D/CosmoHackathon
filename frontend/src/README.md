# Frontend

React/TypeScript/Vite, без UI-библиотек и без сетевых зависимостей. Python отдаёт production-сборку `frontend/dist`. Запуск — `README_RUN.md`, конфигурационный JSON — `docs/api.md`.

## Файлы

`routes.ts` — навигационный контракт: шесть пользовательских задач (Обзор · Поиск · Стресс · Конструктор · Сравнение · Реализация), вторичные вкладки каждой и hash-роутинг. Видимость экрана решает только маршрут; ни одна панель не прячется через CSS.

`App.tsx` — оболочка и состояние: каталог, ручной состав, localStorage, import/export, история отмены, единственный переключатель сценария (он же задаёт сценарий поиска и сценарий конструктора) и пошаговый «Обзор решения». `useDecision.ts` — состояние решения (метод, веса, сценарий, шортлист, baseline) поверх `/api/decision-method` и `/api/decision/recompute`. `comparison.ts` — состояние сравнения, общее для «Поиска» и «Сравнения». `decision.ts` — типы контракта и чистые помощники (`portfolioId`, `composition`, `changes`, `differenceCount`, `plural`).

Экраны: `Overview.tsx` — рекомендация, вердикт STRESS и путь решения с раскрываемыми этапами. `Search.tsx` — три колонки (приоритеты · пространство вариантов · само решение) и вкладки «Шортлист / Почему выбран / Расчёт»; `PreferencePanel.tsx`, `TradeoffPlot.tsx`, `ServiceMap.tsx` — её части. `Stress.tsx` — «Рекомендация / Мой состав / Корректировка бюджета»; `Budget.tsx` — инструмент корректировки (его состояние живёт в хуке, поэтому переход между экранами не теряет расчёт), `LabViews.tsx` — «было → стало» и карта переходов. `Builder.tsx` + `ResultPanel.tsx` — ручной состав и его расчёт. `Compare.tsx` + `ComparisonMatrix.tsx` — цена компромисса впереди плотной матрицы. `Delivery.tsx` — сохранённый выпуск во вкладках «Обоснование / Финансирование / Сервисы / Материалы»; `Finance.tsx` — деньги и ответственность, `Brief.tsx` — карточка решения.

`ui.tsx` — общие примитивы и пять уровней текста: `ViewHead` (экран), `Block` (зона), `object-title` (объект), `Kpi`/`Fact` (значение), `.meta` (техническая подпись). Плюс `Verdict`, `Callout`, `Tabs`, `Tip`, `Disclosure`, `Status`.

Экономических формул на клиенте нет: все метрики, ранги, дельты стратегий, запасы и диагностики приходят с сервера. Клиент считает только представление — доли на шкале, позиции точек и точное сравнение наборов лотов.

## Дизайн

Dark-first Decision Intelligence System. Один глубокий фон `#0B0F14`, три уровня подъёма (`surface` → `card` → `raised`), тонкие линии только там, где они означают структуру или состояние. Единственный холодный акцент `#20B8C8` — выбранное решение; семантика: зелёный PASS, янтарный STRESS и приближение к лимиту, красный FAIL. Токены — в начале `styles.css`; раскладка шести экранов — в `views.css`.

Шаг пространства задан четырьмя значениями (`--s1` 8 px между подписью и значением, `--s2` 14 px внутри блока, `--s3` 24 px между блоками, `--s4` 44 px между секциями), поэтому уровни не склеиваются визуально.

Пять уровней текста и ничего между ними: один заголовок экрана, заголовок зоны с тонкой линией под ним, название объекта моношириной, `label + value` для показателей, `.meta` для единиц, кодов и происхождения. Uppercase-надстрочников (`eyebrow`) нет: уровень задаётся размером, весом и цветом. Технический код стоит рядом с человеческим названием как badge, а не вместо него; единица включена в значение.

Каждый видимый элемент несёт состояние, действие, решение, доказательство или деталь. Пояснения, нужные автору модели, живут в `Tip`, `Disclosure` или во вкладке «Расчёт»; на первом уровне их нет. Ни одна величина не удалена — она перенесена, а не скрыта.

Движение короткое (150–250 мс) и связано с задачей: перенос бюджетной границы BASE/STRESS, подсветка выбранного варианта. `prefers-reduced-motion` отключает переходы, видимый фокус и клавиатурная навигация сохраняются. Шрифты только системные, внешних запросов нет.

## Проверка

`npm run typecheck`, `npm run build`, `npm run test:browser` (Playwright, `KOSMOS_BASE_URL` — адрес работающей сборки). Регрессии репозитория: `node tests/m6_browser.mjs <url> - <out>` и `node tests/m3_browser.mjs <url> <oracle-dir> <out>`.
